# MobLauncher
A fast, clean, open-source Minecraft: Java Edition launcher.

- Builds (instances) with their own folders: Vanilla, Fabric, Quilt, Forge, NeoForge
- All Minecraft versions, Java is downloaded automatically
- Built-in browser for mods, resource packs, shaders and modpacks (Modrinth, CurseForge)
- Mod update checker
- Accounts: Microsoft, Ely.by, offline
- 3D avatar viewer, skins, capes
- Server list with online status and one-click join
- Self-repair and crash analysis
- RAM sliders with warnings, many languages

## Install
Download MobLauncher-Setup.exe from the Releases page.
(Windows may show a SmartScreen warning because the app is not code-signed — click "More info → Run anyway".)

## Build from source
Needs Node.js 20+. Run build-all.bat.
